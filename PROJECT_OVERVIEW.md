# Project Overview

**Title:** Blind to Bright: Offline Danger-First AI Smart Glasses for Safe Outdoor Mobility

**One-line summary:** An experimental AI-assisted wearable system that prioritizes nearby outdoor hazards and delivers concise voice alerts to support visually impaired users.

## Core differentiator
The Danger-First Decision and Priority Engine ranks detected events and selects the most relevant alert first.

## Design principles
1. Supplement existing mobility aids; do not replace them.
2. Prioritize safety-relevant events over general scene descriptions.
3. Keep core perception and speech local where feasible.
4. Keep urgent audio concise and avoid masking environmental sound.
5. Make uncertainty and hardware failure visible.
6. Validate in controlled conditions before real-world user trials.

## First prototype scope
- Start with one camera.
- Add a detector adapter for a compatible model.
- Implement priority ranking and alert suppression.
- Add optional distance sensing.
- Begin with simulation/offline audio.

## Not claimed in this version
Guaranteed collision avoidance, guaranteed 360-degree perception, certified navigation, autonomous route guidance, guaranteed SOS delivery without connectivity, or validated real-world safety performance.
